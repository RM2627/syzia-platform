# Revisão pré-homologação — página pública e portfólio

Autorização posterior do usuário: criar uma entrada permanente Página da empresa na navegação do gestor e uma central para gerenciar/compartilhar a página existente. Reutilizar /empresa/:slug, publicação, identidade, serviços, portfólio, horários e projeção pública. Nenhuma segunda página pública, entidade ou armazenamento paralelo.

A central deve expor status, URL completa derivada da origem atual, Ver página pública, Copiar link com feedback, Editar página, Portfólio e atalhos aos dados existentes. Manter editor de mídia, inclusão/remoção, ordenação e publicação; mostrar prévia fiel. Disponível no celular sem navegação profunda. Ajustar destinos de identidade, portfólio e página no onboarding sem progresso fictício.

Somente gestores autorizados podem administrar; atendentes próprios/compartilhados não ganham direitos. Preservar isolamento e ausência de conteúdos privados na projeção pública. Testar navegação, URL, cópia, autorização, organizações, portfólio, publicação, mobile e regressão. Preservar integralmente migrations históricas.

Entrega: Projeto-Fase-8-Final.zip completo e cumulativo, com relatório específico. Não conectar Supabase real, fazer deploy, publicar externamente, iniciar produção ou nova fase. Parar após entrega.
